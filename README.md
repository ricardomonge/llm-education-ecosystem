# Edu LLM Streamlit Ecosystem

Open-source examples of educational applications built with Streamlit and Large Language Models (LLMs) to support teaching and learning processes.

## Motivation

Large Language Models open new possibilities for feedback, tutoring, and formative assessment.
This ecosystem explores how LLM-powered apps can be designed for educational contexts, with a focus on reproducibility, transparency, and pedagogy.

## What is this?

This repository acts as a HUB for a growing ecosystem of:
- Streamlit educational apps
- Reproducible examples
- Prompt design for education
- Research-oriented notebooks

## Ecosystem (work in progress)

| Repository | Description |
|----------|-------------|
| streamlit-llm-tutor | LLM-powered tutoring app |
| llm-feedback-educativo | Automated formative feedback |
| rubric-evaluator-llm | Rubric-based evaluation with LLMs |

## Intended audience

- Educators and instructors
- Educational researchers
- EdTech developers
- Students interested in AI in education
